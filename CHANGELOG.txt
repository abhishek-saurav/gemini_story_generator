story_generator.py  [MODIFIED]
────────────────────────────────────────────────────────────────────────────────

[2026-04-01 14:00:00] | FEATURE | Added `LANGUAGE_CONFIGS` dict.
  Before: No language support. All stories hardcoded to English. TTS hardcoded
          to lang="en". No language directive in prompts.
  After:  Dict maps 3 language names to:
            tts_code      — gTTS language code ("en", "hi")
            prompt_directive — native-language instruction for Gemini
            tts_note      — user-facing caveat (Bhojpuri uses Hindi TTS)
  Supported: English (en), Hindi (hi / Devanagari), Bhojpuri (hi TTS voice,
             authentic Bhojpuri prose generation via Gemini).
  Reason:  Feature 5 — multi-language support.

[2026-04-01 14:02:00] | FEATURE | Added `LANGUAGES` constant (list of keys from
  LANGUAGE_CONFIGS). Consumed by app.py's language selectbox.

[2026-04-01 14:04:00] | MODIFICATION | Updated `create_advanced_prompt()` to
  accept `language: str = "English"` parameter.
  Before: Prompt hardcoded "modern English" in Language line.
  After:  Looks up `LANGUAGE_CONFIGS[language]["prompt_directive"]` and injects
          it into the ═══ LANGUAGE ═══ section of the prompt. Hindi and Bhojpuri
          directives are written in Devanagari so Gemini responds in that script.
  Reason: Language directive must be native for the model to reliably respond
          in the target language.

[2026-04-01 14:07:00] | FEATURE | Added `create_continuation_prompt()`.
  Before: No continuation capability existed.
  After:  New prompt builder that takes: previous_story (full prior text),
          twist_style (new genre), chapter_num, language. Produces a structured
          prompt with: full previous story as context, twist directive pulled
          from _STYLE_DIRECTIVES, language directive, and chapter requirements
          (no recap, 300–450 words, must end on a hook).
  Reason: Foundation for Feature 3 (story continuation with genre twist).

[2026-04-01 14:10:00] | FEATURE | Added `generate_continuation_streaming()`.
  Before: Only `generate_story_streaming()` existed (images → story).
  After:  New generator function that takes (previous_story, twist_style,
          chapter_num, language). Calls `create_continuation_prompt()`, sends
          text-only content (no images) to `generate_content_stream()`. Same
          AttributeError fallback pattern as `generate_story_streaming()`.
  Reason: Feature 3 — streaming chapter continuation without re-uploading images.
  Notes:  Continuation is text-only (no images). The previous story provides
          all necessary visual context via prose description.

[2026-04-01 14:13:00] | MODIFICATION | Updated `generate_story_streaming()` to
  accept `language: str = "English"` and pass it to `_build_contents()`.
  Before: Language not supported; always used English prompt.
  After:  Language forwarded to `create_advanced_prompt()` via `_build_contents()`.

[2026-04-01 14:15:00] | MODIFICATION | Updated `_build_contents()` to accept
  `language` parameter and forward to `create_advanced_prompt()`.

[2026-04-01 14:17:00] | MODIFICATION | Updated `narrate_story()` to accept
  `language: str = "English"` parameter.
  Before: `gTTS(text=..., lang="en", slow=False)` always.
  After:  `tts_code = LANGUAGE_CONFIGS.get(language, ...)["tts_code"]`
          used for the `lang=` argument. Hindi stories → lang="hi",
          Bhojpuri stories → lang="hi" (with note shown in UI).
  Reason: Feature 5 — language-appropriate TTS voice.

[2026-04-01 14:19:00] | ADDITION | Added `get_tts_note(language)` helper.
  Returns the tts_note string from LANGUAGE_CONFIGS, or None.
  Used by app.py to conditionally show a warning about Bhojpuri TTS limitation.

[2026-04-01 14:20:00] | MODIFICATION | Updated `generate_story_from_images()`
  to accept and forward `language` parameter (backward compat kept).

[2026-04-01 14:21:00] | MODIFICATION | Updated module docstring to list all 5
  features.

[2026-04-01 14:30:00] | MODIFICATION | Updated `save_story()` signature.

           chapters=None, chapter_genres=None) -> str`
  Reason: History entries must store language and per-chapter data for correct
          restoration and multi-chapter display.

[2026-04-01 14:31:00] | MODIFICATION | Updated history entry schema in
  `save_story()` to include new fields:
    "language"       — e.g. "English", "Hindi", "Bhojpuri"
    "chapters"       — List[str] of individual chapter texts
    "chapter_genres" — List[str] of genre per chapter
    "chapter_count"  — int, len(chapters)
  Before: Entry had no chapters list, no language, no chapter_count.
  After:  All fields present. Old entries restored without these fields will
          use fallbacks: `entry.get("chapters", [entry["story"]])` etc.
  Reason: Feature 3 requires per-chapter storage; Feature 5 requires language
          persistence so restored stories narrate in the correct language.

[2026-04-01 14:33:00] | BACKWARD COMPAT | v2.1 history entries (missing
  chapters/language fields) load safely via .get() with defaults.

[2026-04-01 15:06:00] | RENDER PATHS | Restructured from 4 to 5 render paths:
  PATH 1: generate_button → new generation (unchanged except language + chapters init)
  PATH 2: is_continuing → continuation streaming (NEW)
  PATH 3: restore_story → history restore (updated for chapters + language)
  PATH 4: current_story → story persist (updated for chapters + continuation panel)
  PATH 5: else → welcome (updated to show 5 steps instead of 4)
  Reason: PATH 2 is the core of Feature 3. Without a dedicated path, the
          continuation state would be lost between reruns.

[2026-04-01 15:08:00] | PATH 1 | Updated generation path:
  - Reads `language` from sidebar selectbox
  - Stores language in session state
  - Passes language to `generate_story_streaming()`
  - Initialises `all_chapters = [full_story]` and `chapter_genres = [story_style]`
  - Calls `save_story()` with language, chapters, chapter_genres
  - Shows `_show_continuation_panel()` after audio
  - If continue clicked → sets is_continuing=True, calls st.rerun()

[2026-04-01 15:10:00] | PATH 2 | New continuation path:
  - Reads previous chapters from session state
  - Reads twist_style from `st.session_state["twist_genre_select"]`
  - Calls `generate_continuation_streaming(prev_text, twist, chapter_num, lang)`
  - Streams new chapter into `cont_slot = st.empty()`
  - Appends new chapter to all_chapters, genre to chapter_genres
  - Invalidates audio_buffer (sets to None) so full narration is re-generated
  - Saves updated multi-chapter story to history
  - Shows meta bar, download button, narration, and another continuation panel

[2026-04-01 15:14:00] | PATH 3 | Restore path updated:
  - Sets all_chapters and chapter_genres from entry.get("chapters", ...)
  - Sets current_language from entry.get("language", "English")
  - Shows _render_chapters() for multi-chapter restored stories
  - Shows continuation panel if current_images are in session state

[2026-04-01 15:16:00] | PATH 4 | Persist path updated:
  - Renders chapters with _render_chapters()
  - Shows meta bar, download button, narration section, continuation panel
  - If continue clicked → is_continuing=True, rerun

[2026-04-01 15:18:00] | WELCOME | Updated welcome state to show 5 steps

[2026-04-01 15:20:00] | AUDIO INVALIDATION | When a new chapter is added,

  covers the complete story, not just the first chapter.

  After:  Audio covers all chapters combined when narration is triggered.
