⏺ Running at http://localhost:8501. Here's what was actually broken and what was
   fixed:

  ---
  Root causes & fixes

  Bug 1 — st.rerun() inside with st.sidebar:
  Calling st.rerun() raises RerunException which propagates through the
  sidebar's context manager __exit__, leaving Streamlit's internal render state
  dirty. Fixed by removing the st.rerun() call — the button click itself already
   schedules a rerun automatically.

  Bug 2 — is_generating stuck as True after continuation is triggered
  In PATH 1, st.session_state.is_generating = False was the last line of the
  block, but st.rerun() was called before it when the user clicked "Add
  Chapter". RerunException skipped the cleanup line entirely, so is_generating
  stayed True permanently — locking all buttons on subsequent reruns. Fixed with
   try/finally: the flag is now guaranteed to reset before any st.rerun() is
  called.

  Bug 3 — Booleans reset to None instead of False
  The reset handler was setting is_generating and is_continuing to None (the
  generic fallback). Fixed to explicitly set them to False.

  Bug 4 — Wrong return type annotation on _show_continuation_panel
  Annotated as -> None but returns a tuple, causing Pylance errors. Fixed to -> 
  tuple.
